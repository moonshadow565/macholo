# About
Loading mach-o binaries on linux.


# Dependencies:
cmake: https://apt.kitware.com/
llvm: https://apt.llvm.org/
```
sudo apt install build-essential wget git subversion cmake libtool autoconf
sudo apt install libffi-dev libxml2-dev libgnutls28-dev libicu-dev libblocksruntime-dev libkqueue-dev libpthread-workqueue-dev 
sudo apt install libjpeg-dev libtiff-dev libcairo-dev libx11-dev libxt-dev libxft-dev libxrandr-dev
sudo apt install libc++-18-dev libc++abi-18-dev 
sudo apt install libasound2-dev
sudo apt install libgl-dev
```
